# Master Exploratory Data Analysis: Companion Files

These are the companion files for the book *Master Exploratory Data Analysis*. Everything is in one folder:

- the data the book uses: a made-up online coffee subscription, Northpine Coffee Club (`customers.csv`,
  `orders.csv`, `plans.csv`, `cancellations.csv`, `support_tickets.csv`, `survey.csv`, `ab_test.csv`),
- a notebook with every example from each chapter (`chapter-01.ipynb` to `chapter-18.ipynb`),
- the book's chart style (`book.mplstyle`).

## Download

1. Click the green **Code** button near the top of this page, then **Download ZIP**.
2. Find `master-exploratory-data-analysis-main.zip` in your **Downloads** folder.
   - **Windows:** right-click it, choose **Extract All…**, click **Browse**, pick your **Documents** folder and click **Extract**.
   - **Mac:** double-click the ZIP file, then drag the new folder into **Documents**.

You now have a folder called `master-exploratory-data-analysis-main` with all the files inside.

## Use

Section 1.1 of the book shows how to install Python, Jupyter and the libraries. Then start Jupyter, open this
folder and either open a chapter's notebook or create your own notebook in the same folder, so it can find the
data files by name.

The notebooks were tested with Python 3.14, pandas 3.0, NumPy 2.5, SciPy 1.18, statsmodels 0.15, seaborn 0.13,
matplotlib 3.11 and pyarrow.
